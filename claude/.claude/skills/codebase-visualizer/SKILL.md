# Codebase Visualizer

Run the bundled script to generate an interactive HTML visualization:

```bash
python3 visualize.py --output codebase.html
open codebase.html
```

The visualization shows:
- Directory structure
- File sizes
- File types by color
- Expandable/collapsible nodes
